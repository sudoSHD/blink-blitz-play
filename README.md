# BLINK BLITZ! — playable build

Installable web-app build of BLINK BLITZ!, an original rapid-fire microgame show.
Play at **https://sudoshd.github.io/blink-blitz-play/**

On iPad/iPhone: open the link in Safari → Share → **Add to Home Screen**. It runs full screen and works offline.

This repository holds only the built game (generated files), not the source.
